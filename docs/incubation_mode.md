# Incubation Mode – Hatching Mode (Day 21)

This document defines the **Hatching Mode**, which is activated during the final stage of incubation (Day 21). During this phase, eggs must remain undisturbed to allow successful hatching.


## HATCHING MODE (DAY 21)

### Purpose

To provide stable environmental conditions during the final hatching stage and prevent user interference.


### Operating Conditions

* **Egg Turning:** OFF
* **Temperature:** 37.2 °C
* **Humidity:** 70%


### System Behavior

* Egg turning motor is fully disabled
* Temperature control maintains 37.2 °C
* Humidity control increases and stabilizes at 70%


### User Feedback & Alerts

* **OLED Display:** `HATCHING MODE`
* **Wi‑Fi Alert:** `Do Not Open Incubator`
* **Buzzer:** 3 short beeps when entering Hatching Mode


### Safety Notes

* Opening the incubator during this mode is discouraged
* Any critical fault may override this mode to protect the system
